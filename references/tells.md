# 套路登记表：一眼就是「生成的」界面

套路不是坏设计本身。它们大多起初是好主意，后来被默认地、到处地、没有理由地用，才变成一眼看穿的东西。所以这张表**写日期**，而且**不给替代品**：任何「换成这个字体、这个颜色」的清单，几个月后就是下一波套路。「改」一列写的都是做法：用 token、写这个 app 自己的内容、按 `rules.md` 的规格。

做法参考 Taste-Skill（README「致谢」）的 tells 登记表，按 app 界面改写；Taste-Skill 管的是网站落地页，这里只收 app 里会出现的。状态一列说明谁来抓：**lint** 是 `scripts/lint.py`（括号里是规则名，FAIL 或 WARN）；**preview** 是 `preview.py` 的断言；**自评** 是 `rules.md`「看图自评」里要找的。

当前版本：2026-10。

## 1. 第一波（2023–2024）

| 套路 | 谁抓 | 改 |
|---|---|---|
| 紫蓝渐变的按钮、标题、背景，渐变字 | lint（gradient、hardcoded-colour） | 平涂的 `primary`；主色按 SKILL.md 第 1 步的表 |
| 每张卡片底下一层灰色投影；按钮发光 | lint（resting-shadow） | 明度差加 1 px `border`；只有菜单、弹窗用 `elev-2` / `elev-3` |
| 四张一样的卡片，每张顶上一个圆角方块里的 emoji 或图标 | lint（emoji）、自评 | 一列权益，勾加一句具体的话；功能用真实的界面片段演示 |
| emoji 当图标、当项目符号 | lint（emoji） | SF Symbols、Material Symbols Rounded、Lucide |
| 「Get started」「Learn more」「了解更多」「立即体验」 | lint（stock-copy） | 按钮写动作和对象：「开始 25 分钟专注」「导出本月 CSV」 |
| Lorem ipsum、「这里是标题」、灰块代替图片 | lint（placeholder） | 这个 app 的真实样例内容，交付时列出要换的 |

## 2. 第二波（2025）

| 套路 | 谁抓 | 改 |
|---|---|---|
| 标题上方的小号大写字距标签（「PREMIUM」「NEW FEATURE」） | lint（eyebrow，WARN） | 把信息写进标题或副标题，或者删掉 |
| 标题前的「New」「Beta」药丸徽章 | 自评 | 写在副标题里；状态徽章只给真实的状态（已同步、失败） |
| 标题里一个词换颜色、换斜体、加下划线 | 自评 | 一种字、一种颜色，靠字本身强调 |
| 「★★★★★ 10,000+ 用户信赖」「Trusted by」「排名第一」 | lint（invented-proof，WARN） | 没有真实来源就删；评分用系统的评分请求（`rules.md`「共用外壳 → 评分」） |
| 假的数据面板：灰条、甜甜圈图、随手画的折线 | 自评 | 这个 app 真实的数据形状（一周 7 天的专注分钟、本月的分类金额），或者不放 |
| 到处是玻璃：卡片、列表、按钮全半透明 | preview（frost 行）、自评 | 玻璃只给栏和浮层（`rules.md`「不要」） |
| 每一屏都是同样的大标题 + 卡片网格 | 自评（同一种布局） | 按屏的用途选：列表、编辑画布、对话、单个决定 |

## 3. 第三波（2025–2026）：「修正」变成了新的样子

前两波的通用解法是「去掉装饰，做成编辑部风格的克制界面」。模型把这个解法整个学走了，于是它本身成了新的套路。

| 套路 | 谁抓 | 改 |
|---|---|---|
| 等宽字的小标签、时间戳、「v1.0.3」版本号当装饰 | lint（monospace，WARN） | 等宽只给代码；数字对齐用等宽数字（`tabular-nums`、`.monospacedDigit()`） |
| 「01 / 02 / 03」「STEP 2」编号当装饰 | lint（index-numbering，WARN） | 顺序靠位置和文字；真是步骤就用系统的分步控件或 `<ol>` |
| 奶油底配陶土色、焦糖色，当「温暖高级」 | lint（hardcoded-colour） | 中性色固定是石墨，暖色只在图标和品牌插图里 |
| 「回避美学」：什么套路都没有，也什么内容都没有，一屏只有一行灰字 | 自评（内容完整、空洞） | 把这一屏该有的内容写全：真实的任务名、金额、示例图 |
| 文案里的「不只是 X，更是 Y」、三连排比、「赋能」「一站式」「无缝」 | lint（stock-copy） | 一句话说清它做了什么 |
| 字重 700 当「有力」 | lint（weight-700） | 400 / 510 / 590；iOS 大标题按系统写法 |

## 4. 为什么只删掉还不够

一屏去掉了所有套路、却没有内容的界面，是一张有礼貌的空白：规矩，但谁都能从「品类 + 禁止清单」里猜出它。套路原本填的是**内容**该在的位置。所以写界面时先写内容（这个 app 的真实对象、数字、状态，`rules.md`「文案」），再排版，最后才是 lint 和自评；删掉套路空出来的地方，用内容、用更大的那一个主角、用图标自己的主体填，不换一种装饰。

## 维护

每次评审里发现一个新的重复出现的样子，就加一行：套路、谁抓、改（写做法，不写替代品），并改上面的版本日期。能用正则抓的，同时加进 `scripts/lint.py` 的 `RULES`，并在 `examples/lint/before.html` 里加一行能触发它的写法。
